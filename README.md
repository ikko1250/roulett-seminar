# ルーレット

ブラウザで動くシンプルなルーレットです。ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。

## 使い方

画面は「抽選」と「項目入力」の2つのタブに分かれています。設定はすべてブラウザに保存されます。

1. **項目入力**タブで、項目を1行に1つずつ入力します。入力した内容はすぐ抽選に反映されます。
   - 「テキストを読み込む」ボタン、またはテキスト欄へのドラッグ＆ドロップで、1行1項目のテキストファイルを読み込めます（UTF-8 / Shift_JIS 対応）。
2. **抽選**タブの「候補」で、項目ごとに設定できます。
   - 左のチェックを外すと、その項目を一時的に抽選から外します（項目自体は残ります）。
   - 「1倍／2倍」ボタンで、その項目の当たる確率（扇形の大きさ）を2倍にできます。右端に各項目の確率が表示されます。
3. 「回す」ボタンを押すと、ルーレットが回転して結果が表示されます。
4. 「当たった項目を次回から外す」をオンにすると、当たった項目のチェックが自動で外れます。「すべて有効に戻す」で全項目のチェックを戻せます。

## ローカルで確認

`index.html` をブラウザで直接開くか、簡易サーバーを起動します。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## GitHub Pages で公開

1. このディレクトリを GitHub リポジトリに push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」にし、ブランチ `main`、フォルダ `/ (root)` を選んで保存します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
