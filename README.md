# ルーレット

ブラウザで動くシンプルなルーレットです。ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。

## 使い方

1. 右側のテキスト欄に項目を1行に1つずつ入力します（入力内容はブラウザに保存されます）。
   - 「テキストファイルを読み込む」ボタン、またはテキスト欄へのドラッグ＆ドロップで、1行1項目のテキストファイルを読み込めます（UTF-8 / Shift_JIS 対応）。
2. 「回す」ボタンを押すと、ルーレットが回転して結果が表示されます。
3. 「当たった項目を候補から外す」にチェックを入れると、当たった項目が結果表示の少し後に候補から外れます。外した項目は「すべて候補に戻す」で戻せます。

## ローカルで確認

`index.html` をブラウザで直接開くか、簡易サーバーを起動します。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## GitHub Pages で公開

1. このディレクトリを GitHub リポジトリに push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」にし、ブランチ `main`、フォルダ `/ (root)` を選んで保存します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
